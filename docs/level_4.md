# 第四关：储物间弹射机关

按本次用户确认的流程制作。入口为选关界面第二排第一扇门，编号 4，完成记录使用独立编号 4。继续使用全局背景音乐以及现有拾取、放置和通关音效。

## 操作与流程

只有叉子、漏斗可以拾取到右侧背包并拖回场景。右键拖动连续旋转，滚轮或 Q/E 微调，允许 360° 旋转和任意场内位置，不吸附答案位置。关内不添加文字、高亮或引导手。

运行时耙子倾斜，钥匙从齿间支撑处释放并落到铲面。铁球沿耙柄滚动，经玩家摆放的叉子落到铲柄右侧；右侧实际接触产生力矩，铁铲以固定木楔接触处为支点翘起。钥匙仍在铲面附近时，按铲面切向速度释放，之后完全由刚体重力和碰撞决定轨迹。叉子、漏斗的位置不参与计算弹射方向。

钥匙必须先向内穿过漏斗口，再穿过下方出口，最后进入柜子顶部接收区域才开柜；碰到外壁不能开锁。柜子开门动画结束、种子显露时记录通关，停留后返回选关。

失败或刷新恢复耙子、铁铲、铁球、钥匙和柜子，保留叉子与漏斗的收集、摆放和角度。运行、开柜时禁止编辑道具，刷新和返回选关仍可使用。

## 物理实现边界

铁球与钥匙为连续碰撞检测刚体。耙子和铁铲采用有机械限位的 AnimatableBody2D；铁铲受接触启动，以右侧负载力矩计算角加速度，不是自由翻滚的刚体。钥匙在耙子上的初始齿间支撑由冻结状态表达，耙子倾斜后释放；弹射速度来自铁铲角速度与钥匙到支点的距离。

耙子用贴图 alpha 轮廓生成碰撞；叉子表面导向、铲面浅槽和漏斗内壁使用贴合绘制表面的线段碰撞。它们是侧视图中的承接面，不把整张图片矩形当成实体。漏斗为空心，柜子通道在耙子的后层，因此其碰撞只接收钥匙，不阻挡前层耙柄上的铁球。
