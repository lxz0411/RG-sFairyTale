# 第三关 餐室连锁机关

依据用户确认的新素材 `第三关素材/第三关 拆分 改/第三关 拆分` 及机关逻辑制作。使用背景底图叠加活动部件还原初始状态，而非将初始状态烘焙成静态背景。关卡入口仍为选关门牌 3，通关后返回选关。

## 玩家操作

只有钟针组和酒瓶配重需要收集、摆放。沿用教学关式自由拖放、右键连续旋转、滚轮和 Q/E 微调；没有固定位置吸附、文字或高亮提示。书、齿轮、右侧活动边框、吊钟下方灰色连杆和棕色连杆属于自动联动机关，不可当作道具拿走。不存在四本骨牌和喂食汤匙。

## 确认后的连锁

1. 苹果从蓝色天窗落下。缺少钟针导向时，它进入下槽并卡在书本下部，不能推动书。钟针正确承接时，苹果沿上方细横杆撞击书的上部。
2. 书受撞翻倒，实体书面搭成临时桥。书与承压端接触先推动一小段，苹果经过桥面继续压下灰色连杆。
3. 灰杆到达下方限位后驱动齿轮，左侧只下降画框右边的活动边框；画作主体不移动。苹果进入第二层木轨向左滚，再经下降的边框进入下一层向右滚。
4. 酒瓶从运行开始就受重力影响。放在右侧托盘上的酒瓶直接压低托盘，带动棕色连杆旋转到下方木块处限位，左侧杆件接通最后一层道路。此动作不等待书、灰杆或齿轮解锁。
5. 苹果沿末段木槽进入盘子，接触盘面后耗散运动，在盘内连续停稳至少 0.55 秒才通关。随后苹果淡出表示被吃掉，星星点亮，保存编号 3 的进度。

## 实现边界

苹果和酒瓶使用连续碰撞检测的刚体。书与两组连杆采用接触驱动、带机械限位的活动碰撞体：书翻倒具有受撞初速度、随角度变化的加速度和落桥姿态；灰杆的位移与齿轮、活动边框联动；棕色连杆仅在酒瓶实际接触托盘时下压。它们不是全部自由刚体。运行中不通过 Tween 或坐标路线搬运苹果。

可交互贴图使用 alpha 轮廓生成碰撞，背景木轨沿可见边缘建立实体支撑。灰色承压端在下限位回缩，让苹果能够离开；末段木槽与盘面分别增加滚动阻力及接触阻尼，避免苹果高速飞过浅盘。

自动回溯与刷新恢复所有活动机关及苹果，保留玩家道具的收集、摆放和朝向。运行或回溯时不可编辑；返回菜单与通关进度继续复用现有框架。
