# 物理测试场景

打开 `test_physics.tscn` 后按 F6。

- 右侧物品栏使用与寻找场景共用的五个等大、均匀竖排的圆角正方形格子，每格只显示道具图标。
- 左键拖出图标才显示真实道具：木板 240×24，小球半径 20；放置后仍可再次拖动。
- 选中木板后，滚轮每次旋转 5°，Q / E 连续旋转；也可在木板上按住右键绕中心旋转。
- 木板尺寸固定，放置后作为固定支撑；小球松手后恢复重力、摩擦和碰撞。
- 将小球放到倾斜木板上方，可观察下坡滚动。球面的偏心圆点用于显示自转。
- 拖回右侧物品栏可归还物品；左上角圆箭头全部重置，Esc 归还正在拖动的物品。

静态背景、地面、边界、右侧物品栏、木板、小球及碰撞形状均保存在场景节点中。
脚本只管理输入、位置、旋转和物理启停，不生成静态场景。

验证：Godot --headless --path . --script res://tests/test_physics_flow.gd
附加鼠标交互与截图验证：省略 --headless，并在命令末尾添加 -- --visual-check。
